Contribute

Statlib welcomes all kinds of contributions, including questions, examples, formalization requests, project proposals, and pull requests.

Our team is also actively building projects across core areas of statistics; see the Projects page for current directions.

Open an issue or a pull request against stat-lib/statlib

Code follows Mathlib's style and naming conventions. AI-assisted contributions should be understood by the contributor and disclosed in the PR description.
